knowledge pages, and the other candidates turned up while looking, so the
next project can be picked from a list instead of a search box.

**Searching it:** use your browser's find (⌘F / Ctrl+F) or GitHub's search
on this file. The *Tags* column uses the same words every time, so searching
for one of these finds everything that matches:

- type: `amigurumi`, `accessories`, `appliques`, `blankets`, `clothing`,
  `home`, `technique`
- level: `beginner`, `easy`, `intermediate`, `experienced`
- construction: `no-sew`, `top-down`, `any-size`, `sized`, `multi-part`,
  `in-the-round`
- yarn: `chunky`, `chenille`, `worsted`, `DK`, `sport`, `fingering`, `cotton`
- technique: `tunisian`, `mosaic`, `lace`, `ribbing`, `granny-square`,
  `colour-change`, `chart`
- pattern: `free-pattern`, `paid-pdf`, `pattern-in-description`,
  `captions-only`, `no-captions`
- length: `quick` (under 10 min), `long` (over 40 min)
