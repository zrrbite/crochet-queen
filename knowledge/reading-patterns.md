# Reading patterns

## US and UK terms

The same names mean different stitches in US and UK patterns. A UK "double
crochet" is a US single crochet. This repo uses US terms.

| US                        | UK                          |
| ------------------------- | --------------------------- |
| single crochet (sc)       | double crochet (dc)         |
| half double crochet (hdc) | half treble (htr)           |
| double crochet (dc)       | treble (tr)                 |
| treble (tr)               | double treble (dtr)         |
| skip                      | miss                        |
| gauge                     | tension                     |
| yarn over (yo)            | yarn over hook (yoh)        |

Chain and slip stitch are the same in both.

**Telling them apart:** UK patterns have no single crochet. If you see `sc`,
the pattern is US. If the smallest stitch it uses is `dc`, it is probably UK.

## Abbreviations

| Abbr.      | Meaning                                                       |
| ---------- | ------------------------------------------------------------- |
| ch         | chain                                                         |
| sl st      | slip stitch                                                   |
| sc         | single crochet                                                |
| hdc        | half double crochet                                           |
| dc         | double crochet                                                |
| tr         | treble crochet (some patterns say "triple crochet")           |
| st / sts   | stitch / stitches                                             |
| R / Rnd    | round (worked in a circle) or row (worked back and forth)    |
| MR         | magic ring (also: magic circle, magic loop)                   |
| inc        | increase: 2 sts in the same stitch                            |
| dec        | decrease: 2 sts worked together into one (e.g. `sc2tog`)      |
| invdec     | invisible decrease, worked through front loops (amigurumi)    |
| FO         | fasten off                                                    |
| yo         | yarn over: wrap the yarn over the hook, back to front         |
| sk         | skip                                                          |
| sp         | space, e.g. `ch-2 sp` is the gap under a chain of 2           |
| BLO / FLO  | back loop only / front loop only                              |
| rep        | repeat                                                        |
| RS / WS    | right side / wrong side                                       |

## Notation

- `*...*; rep from * around`: work the part between the asterisks, then
  keep repeating it until you reach the end of the round.
- `[...] 3 times`: work what's in the brackets three times in total.
- `(2 dc, ch 1, 2 dc) in next st`: work everything in the parentheses into
  the same stitch.
- `— 30 sts` at the end of a round: how many stitches you should have once
  it's done. Count before you join; it's the cheapest place to find a mistake.
  Many patterns write it in parentheses instead, as `(30)`.
- `in next st` means the next unworked stitch. `in same st` means the one you
  just worked into.
- `around` means to the end of the round.

Unless a pattern says otherwise, insert the hook under **both** top loops of a
stitch, the "V" you see from above.
