# Basic stitches

US terms. Each stitch starts with one loop on the hook.

## Slip knot

The loop that starts everything. It doesn't count as a stitch.

1. Make a loop in the yarn, with the tail end hanging behind it.
2. Reach through the loop, catch the working yarn (the end attached to the
   ball), and pull a new loop through.
3. Put that loop on the hook and pull both ends to snug it. It should slide
   on the hook, not grip it.

## Chain (ch)

Yo, pull through the loop on the hook. That's one chain.

When counting chains, don't count the loop on the hook or the slip knot.

## Slip stitch (sl st)

The flattest stitch. Mostly used to join rounds and to move along the work
without adding height.

Insert hook into stitch, yo, pull through the stitch **and** the loop on the
hook in one go.

## Single crochet (sc)

1. Insert hook into stitch, yo, pull up a loop (2 loops on hook).
2. Yo, pull through both loops.

## Half double crochet (hdc)

1. Yo, insert hook into stitch, yo, pull up a loop (3 loops on hook).
2. Yo, pull through all 3 loops.

## Double crochet (dc)

1. Yo, insert hook into stitch, yo, pull up a loop (3 loops on hook).
2. Yo, pull through 2 loops (2 loops left).
3. Yo, pull through the last 2 loops.

A rhythm that helps: *yarn over, in, pull up; over, through two; over, through
two.*

## Treble crochet (tr)

1. Yo **twice**, insert hook into stitch, yo, pull up a loop (4 loops on hook).
2. [Yo, pull through 2 loops] 3 times.

## Stitch heights

Taller stitches need a chain at the start of a row or round to lift the hook
to the right height. Usual lengths:

| Stitch | Starting chain |
| ------ | -------------- |
| sl st  | none           |
| sc     | ch 1           |
| hdc    | ch 2           |
| dc     | ch 2 or ch 3   |
| tr     | ch 4           |

Whether that chain **counts as a stitch** varies by pattern, and getting it
wrong is the usual cause of a round that's one stitch off. The pattern should
say. See [flat circles](../techniques/flat-circles.md#does-the-starting-chain-count)
for why some designers don't count it.

## Split stitch

Not a stitch: a mistake. It happens when the hook goes *through* the yarn
instead of under the loops, catching only some of its plies. It looks fuzzy and
uneven. Pull back that one stitch and redo it.
